# Redmine KaTeX Plugin

Fast, client-side math rendering for Redmine 7.0+ (Rails 8 / Propshaft) using KaTeX.

## Features
- Blazing fast math rendering via KaTeX.
- CommonMark `math_dollars` native extension enabled.
- Safe, Zeitwerk-compliant architecture.
- Handles AJAX requests for live previews seamlessly.

## Installation
1. Run `./getKaTeX.sh` to download the assets.
2. Move this directory to `plugins/redmine_katex`
3. Restart Redmine.
